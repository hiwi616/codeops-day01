# My Dishes App

A small React app built with Vite that renders a list of dishes using
composable components and props.

## What it is
- `Header` — page title and intro
- `Dish` — renders a single dish's name and price from props
- `App` — renders the dishes array with `.map`

## How to run it
1. Clone this repo
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev`
4. Open the local URL shown in the terminal
