# DATA.md — Query Strategy, Lifecycle & Metadata Sources (Day 44)

| Query Key / Data Source               | Where It Runs                   | Refresh Rule                                  | Justification                                                                                                                      |
| :------------------------------------ | :------------------------------ | :-------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------- |
| Direct DB (`getDishes()`)             | Server Component (`/menu`)      | Hourly ISR (`revalidate = 3600`)              | Catalog changes infrequently; server pre-rendering eliminates client waterfalls.                                                   |
| Sitemap Generator (`sitemap()`)       | Server Route (`/sitemap.xml`)   | On build / Request time                       | Dynamically pulls all 15 authentic dish IDs to publish an accurate XML sitemap to search engines.                                  |
| Dynamic Metadata (`generateMetadata`) | Server Component (`/menu/[id]`) | On build / Request time                       | Queries individual dish record to generate rich Open Graph and Twitter Card tags per dish.                                         |
| `/api/orders/${id}`                   | Client Leaf (`useSWR`)          | `refreshInterval: 5000`                       | Real-time status polling for kitchen updates seeded with server `fallbackData` to avoid first-paint spinners.                      |
| `/api/dishes?q=${debounced}`          | Client Leaf (`useSWR`)          | On debounced input change (`null` when empty) | Dynamic keystroke search; 300ms debounce prevents request floods, and `keepPreviousData: true` prevents layout flashing.           |
| Cart State                            | Client Context                  | LocalStorage synced                           | Private to tab; no network overhead until checkout submission.                                                                     |
| Runtime Environment (`lib/env.js`)    | Node.js Runtime / Edge          | Application boot                              | Validates public (`NEXT_PUBLIC_APP_URL`) and private variables using Zod before server execution to ensure canonical URL accuracy. |
