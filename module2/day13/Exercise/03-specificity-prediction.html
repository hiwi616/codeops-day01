Exercise 3: Specificity

Prediction

The paragraph below is targeted by three rules: an element selector (p), a class selector (.highlight), and an ID selector (#unique-paragraph), each setting a different color.

Specificity scores (as ID, class, element counts)

  • p { color: blue; } → specificity (0, 0, 0, 1) - one element selector.
  • .highlight { color: green; } → specificity (0, 0, 1, 0) - one class selector, which outranks any number of element selectors.
  • #unique-paragraph { color: red; } → specificity (0, 1, 0, 0) - one ID selector, which outranks any number of class or element selectors.

Prediction: the ID selector wins, so the paragraph should render in red - ID has the highest specificity of the three, regardless of the order the rules are written in.

Result

This paragraph is targeted by all three rules. Its actual rendered color confirms the winner.
