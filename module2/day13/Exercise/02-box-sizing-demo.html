Exercise 2: content-box vs border-box

Both cards below are declared with width: 300px, padding: 24px, and a 2px border.

content-box (default)

This card is content-box.

Math: 300px content + 24px padding × 2 sides (48px) + 2px border × 2 sides (4px) = 352px rendered width.

border-box (fixed)

This card is border-box.

With box-sizing: border-box, the padding and border are subtracted FROM the declared width instead of added on top, so the rendered width stays exactly 300px.
