Exercise 5: Hex → RGB → HSL

Hover each swatch to see its lighter hover shade (lightness increased by 15%, hue and saturation unchanged).

Forest Green

hex: #1F5C3A

rgb: rgb(31, 92, 58)

hsl: hsl(147, 50%, 24%)

hover: hsl(147, 50%, 39%)

Sunset Gold

hex: #F0B429

rgb: rgb(240, 180, 41)

hsl: hsl(42, 87%, 55%)

hover: hsl(42, 87%, 70%)

Clay Red

hex: #B3261E

rgb: rgb(179, 38, 30)

hsl: hsl(3, 71%, 41%)

hover: hsl(3, 71%, 56%)

Converting to HSL first, then only changing the lightness component for the hover state, keeps the hue and saturation identical - guaranteeing the hover color is a true lighter version of the same color, rather than a color that happens to look close.
