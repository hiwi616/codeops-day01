# Habesha Eatery Mini Site

## Description

This project is a two-page accessible restaurant website built using semantic HTML and CSS.

## Pages

- index.html
- contact.html

## How to Run

1. Download or clone the repository.
2. Open `index.html` in any modern web browser.
3. Navigate between pages using the navigation menu.

## Accessibility Features

- Semantic HTML (`header`, `nav`, `main`, `section`, `footer`)
- One `<h1>` on each page
- Keyboard-accessible navigation
- Proper labels for every form input
- HTML validation (`required`, `type="email"`, phone pattern)
- Meaningful image `alt` text
- Google Map iframe with a descriptive `title`
- Tables include `<caption>` and `scope="col"` on headers
- Responsive layout using CSS
